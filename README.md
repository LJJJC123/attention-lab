# 注意力工作台 · Attention Lab

一个对抗手机分心、提升深度工作时长的本地训练工具，桌面和手机都能用。包含两个环节：

1. **处理速度热身**（约 3 分钟）——ACTIVE 试验范式，中央 + 周边分裂注意，呈现窗口随表现自适应调整
2. **专注块**（15 / 25 / 45 分钟）——记录切屏事件的次数与时长

报告页只呈现实测数据，并据此给出下一步建议。样本不够时它会保持沉默，
**测不到的东西它显示「未测量」，而不是显示 0%**。

打开就是控制面板：选时长 → 按开始。介绍文字在下面，不挡路。

## 在手机上用

用手机浏览器打开网址 → 「添加到主屏幕」。之后它会全屏运行、可离线、数据存本地。

两种专注块模式，区别不是外观，是数据可信度：

| 模式 | 屏幕 | 分心数据 |
|---|---|---|
| **亮屏 · 记录切屏** | 申请屏幕常亮，不熄屏 | 离开页面 = 真的切走了，可测 |
| **扣屏 · 只记时长** | 正常休眠 | **不测**，专注时长照常计入 |

为什么必须分开：手机上你得把手机扣下，而**屏幕休眠和「拿起手机刷抖音」触发的是同一个
`visibilitychange` 事件**。不区分就会把一次 25 分钟的专注块记成「离开 25 分钟」——
不是误差，是彻底失真。所以扣屏模式干脆不测，报告也不会把它的空数据当成 0% 混进分心统计。

浏览器不给屏幕常亮权限时（iOS 需 Safari 16.4+），界面会直接说明这次切屏数据会偏高。

## 运行

开发（带热更新，**不注册 Service Worker**）：

```bash
npm install
npm run dev      # http://localhost:4310
```

生产构建 + 本地预览（与线上行为一致，含 SW 与 PWA）：

```bash
npm run serve    # = npm run build && node tools/serve.mjs
```

构建产物在 `out/`，约 1.2 MB 的纯静态文件（含约 270 KB 自托管字体）——没有服务端、
没有数据库、没有环境变量，运行时也不请求任何第三方域名。
**部署方式（GitHub Pages / Netlify / Vercel / Cloudflare Pages / 自有 Nginx）见 [DEPLOY.md](DEPLOY.md)。**

手机访问：手机与电脑连同一 WiFi，打开终端打印的 `network: http://192.168.x.x:4310`。
部署上线后随时随地打开，「添加到主屏幕」即可当 App 用。

## 自查验证

### 1. 逻辑层（27 项断言，零框架）

```bash
npm run test:unit
```

覆盖自适应难度的上下限与步进节奏、种子可复现性、localStorage 的损坏数据降级、
衰减曲线的边界、时段直方图、`drift` 读取入口的任意脏数据不抛异常、
建议生成的「不编造」约束，以及**扣屏模式的诚实性**——未测量的块不得被当成 0% 分心、
`driftMode` 字段缺失或损坏时的兼容行为。

### 2. 对比度门禁（18 对，零依赖）

```bash
npm run test:contrast
```

`tools/contrast.mjs` 从 `tokens.css` **真实读取 token**，走OKLCH → sRGB → WCAG
算出实际对比度，逐对检查下限（正文 4.5:1、控件与焦点环 3:1），
任何一对不达标就以非 0 退出码失败——可直接进CI。

它存在的理由：设计变量写成OKLCH 时，肉眼判断不出`oklch(58% 0.115 78)`
和`oklch(62% 0.135 78)` 的区别，但后者是 4.94:1、前者只有 4.20:1。
这个工具第一版就抓出了 `--accent-dim` 不达标——而它正是 7 天柱状图的数据条颜色，
也就是「必须读得出来」的那根条。

### 3. 浏览器端到端（76 项断言，真实计时）

```bash
npm run serve                # 构建并起在 http://localhost:4310
node tests/e2e.mjs http://localhost:4310/
```

`tests/harness.html` 会被复制到 `public/e2e-harness.html`（与站点同源，驱动脚本因此
可以进入 iframe 内部操作真实 DOM），用 headless Edge 完整点一遍产品：60 题热身 →
专注块 → 切屏 → 结束 → 报告 → 关于，覆盖：

- 四档宽度（320/375/414/768）无横向溢出
- 三种真实手机视口（iPhone SE / iPhone 14 / 小屏安卓）下 stage 保持正方、**作答按钮不被挤出屏幕且≥44px**
- 触屏作答按钮真的能推进热身（不是只渲染出来）
- 扣屏模式的 HUD 显示「未测量」而非「0 次」，且落盘 `driftMode:'off'`
- 报告把未测量块标为「未测量」，分心占比不出现在无实测数据时
- PWA 资产齐备（manifest / 图标 / sw.js / `viewport-fit=cover` / apple-touch-icon）
- 全站无「大脑年龄」评分，「预防」只出现在免责语境中
- **首页控制台的几何**：开始按钮在首屏内、位于说明文字之上、高度 ≥44px、测量网格已渲染
- **退出与放弃**：热身和专注块都有退出入口；放弃后 `localStorage` 里确实没有多出块；
  练习进行中导航被锁（点锁定 tab 不会丢掉正在跑的会话）；退出弹窗提供「记录/放弃」两条出路且 Esc 可退回

三个注意点：

- `public/` 是**构建时快照**。改过 harness 后必须重新 `npm run build`，否则 404。
- `tests/e2e.mjs` 的默认端口是 4310；若你起在别的端口，必须把地址作为参数传进去，
  否则它会静默去访问一个不存在的服务。
- harness 里 `w.location.reload()` 之后必须重新赋值 `w = f.contentWindow`，
  否则后续 `w.localStorage` 抛错（这个坑踩过一次）。
- **reload 之后必须调 `goHome()` 点回「今天」**。应用把当前 tab 同步进 URL（`?t=report`），
  刷新会停在报告页——这是正确的产品行为，但意味着首页控制台与热身舞台不在 DOM 里，
  十几个断言会因与被测项无关的原因失败。

断言用class 选择器（`.console-go` / `.focus-go`）而非文案匹配。
文案匹配是隐藏的定时炸弹：`开始 {targetMin} 分钟` 里内嵌了时长，
默认时长一改就会静默失败。

### 4. 手工确认

1. 点「开始今天」→「跳过，直接开始」可跳过热身（手机上前置 3 分钟是真实门槛）
2. 热身中点屏幕下方「相同 / 不同」作答；桌面上也可用 `F` / `J`
3. 专注块选「扣屏」模式 → HUD 应显示「未测量」；选「亮屏」→ 屏幕常亮生效
4. 结束 → 报告页扣屏行应标「未测量」，分心占比不引用它
5. 练习中途点「退出」→ 应出现两问；选「放弃，不记录」后回到首页且报告里没有多出这个块
6. 练习进行中点「报告」→ 标签应变灰且点了没反应（防止误触丢掉当前这一轮）
7. 手机浏览器「添加到主屏幕」，断网后重开应仍可用

## 设计取舍

| 决定 | 理由 |
|---|---|
| 处理速度训练作为唯一主打题型 | ACTIVE 是认知训练领域最强的长期证据，记忆与推理训练在同一试验中未显示痴呆风险收益 |
| 呈现窗口 200–900ms，难度每 4 题最多调一次 | setTimeout 会漂移几十毫秒，正好是这个任务要测的量级，因此所有边界用 `performance.now()` 计算并重新对齐 |
| 不用「大脑年龄」评分 | 没有经验证的单一数字能对应认知功能；Melby-Lervåg 2016 元分析对远迁移的结论也是否定的 |
| 分心检测用 `visibilitychange` + `blur` 双信号，800ms 以下丢弃 | 单信号会漏报或误报；亚秒级切换是标签栏悬停噪声 |
| **手机上分成亮屏 / 扣屏两种模式，而不是自动判断** | 锁屏和拿起手机是同一个事件，程序无法区分。猜错的代价是报告出现自信的假数据；让用户选并如实标注，代价只是多一次点击 |
| **未测量的块从分心统计中剔除，而不是记为 0** | 把空数据当 0% 会让报告显得比实际更优秀，这是这个产品最坏的一种错 |
| 周边刺激偏移用 stage 自身百分比，不用 `vmin` | `vmin` 是视口短边；竖屏手机上会把刺激甩出 stage，题目静默退化成更简单的中央任务，难度曲线失真 |
| 离开超过一个专注块时长要问，不自动续计 | 手机上最常见的消失是「锁屏睡了一小时」。静默续计等于凭空给用户记功 |
| 跳过热身是独立动作，不是取消 | 手机上 3 分钟热身是真实门槛；原来「跳过」会弹回首页，等于强迫做完 |
| 不做账号、不做后端 | 决策已定为「先验证产品」；localStorage 足够，且零隐私风险 |
| 全栈框架 Next.js | 决策已定，为后续多端同步预留演进空间，但当前零后端代码 |
| 图表用手写 div / SVG 而非图表库 | 7 根柱子不值得引入一个依赖 |
| 导航请求网络优先，静态资源缓存优先 | 训练页必须跑最新代码；旧的自适应参数会产出用户无法信任的数据。带 hash 的静态资源则可放心长期缓存 |
| `output: 'export'` 纯静态导出，不用 Node 服务器 | 没有服务端组件、没有 API、没有会话，全在 localStorage。服务器进程买不到任何东西，纯静态能丢进任何托管且关掉服务器也能用 |
| 基路径可配置（`BASE_PATH`） | GitHub Pages 把项目放在 `/<repo>/` 下，Next 默认发根绝对路径资源 URL，不配就是满屏 404 且页面退化成无样式纯文字 |
| SW 注册路径从 `<html data-base-path>` 读 | 在 `'use client'` 模块里 `process.env.NEXT_PUBLIC_BASE_PATH` 不会被内联（Next 保留表达式本身），import 常量拿到的是 `""`，注册路径会退回 `/sw.js` 而不受作用域控制 |
| **首页做成控制面板，不是介绍页** | 时长选择 + 开始按钮占第一屏上半，介绍降级到下方。手机上打开就能直接按，不需要先读三段话才知道这是什么 |
| **`next/font` 自托管 IBM Plex Sans + Mono，不用 CDN `<link>`** | 一个 Google Fonts 链接会给「数据只存在你浏览器里」这个核心承诺送一个追踪信标。构建期下载 = 零运行时第三方请求 |
| **CJK 不做 webfont** | 完整中文字库数 MB，会悄悄抵消隐私承诺，也让首屏变慢。中文回落平台字体（PingFang SC / 微软雅黑） |
| 圆角 16px → 2/4px，卡片改1px 实线边框 + 顶部内发光 | 仪器面板是平的、有刻线的，不是浮起来的软卡片。阴影浮起是消费级 SaaS 的默认观感 |
| 页面铺双层测量网格（8px 细 + 64px 主），舞台加内衬网格 | 底纹提供尺度参照，让「宽 / 窄」「对齐」这类判断不用靠猜。径向 mask 让它在页面边缘淡出，不喧宾夺主 |
| 所有数字统一等宽 + `tabular-nums` | 仪表读数不跳动是「像仪器」的核心。比例数字在倒计时里逐帧宽度变化，读起来是抖的 |
| tab 同步进 URL（`?t=report`），用 `replaceState` | 报告页可分享、可收藏、刷新保持。切 tab 不进历史栈，所以不会污染返回键 |
| 测试断言用 class 选择器而非文案匹配 | `开始 {targetMin} 分钟` 内嵌时长，默认时长一变断言就静默失败——比没有测试更糟 |
| **练习进行中锁住导航 tab** | 切 tab 是 SPA 内部跳转，`beforeunload` 不触发，承载计时的组件直接被卸载——20 分钟白练且无提示。返回键也一并拦住，否则禁用的按钮只是摆设 |
| **退出做成两问而不是一个按钮** | 「结束并记录」和「放弃不记录」都是对的，取决于那段时间是不是真的专注。替用户猜错，损失的是用户对整个报告的信任 |
| 放弃的块完全不入库（含热身） | 半截热身不是样本；记下来会让 4 题的运行冒充成一次真实速度测量 |
| Tab 锁定用 `aria-disabled` 而非 `disabled` | `disabled` 会把按钮移出tab 序列，键盘用户直接跳过、无从得知原因 |
| 退出弹窗内做焦点陷阱 + Esc 返回 | 弹窗后面是仍在运行的计时器，Tab 出去会落在因练习锁定的死控件上，读起来像坏了 |
| `serve.mjs` 优先读 `PORT` 环境变量，`--port` 作为本地回退 | 宿主平台注入 `PORT` 并经反向代理访问；服务只认 `--port` 会监听错端口，健康检查失败后平台**静默保留旧部署**——deploy 报 success 但线上没变 |

## 已知边界

- **手机扣屏之后把手机翻过来看时间，本页面看不见。** 报告里的「分心」是分心的一个子集，不是全部。
- 扣屏模式不产生分心数据，这是设计而非缺陷：锁屏与拿起手机在网页层无法区分。
- 屏幕常亮在部分浏览器/省电模式下会被拒绝，此时亮屏模式的切屏数会偏高，界面会提示。
- 热身成绩只说明该题型上的表现，不等于全天专注状态，也不代表记忆力。
- 清除浏览器数据会一并清掉 `attnlab.v1`，没有服务端副本。「关于」页可导出 JSON 自留。
- Service Worker 只在生产构建注册。改了 `public/sw.js` 要把里面的 `CACHE` 版本号 +1，
  否则老用户永远命中旧缓存。

## 结构

```
app/          页面与全局样式（tokens.css 承载全部设计变量）
components/   Warmup（热身）· FocusBlock（专注块）· Report（报告）
lib/engine.mjs    自适应难度引擎，纯函数，无 DOM，可在 node 下直接测试
lib/store.mjs     localStorage 读写 + 派生统计 + 建议生成 + driftMode 可信度判定
lib/useDrift.js   分心检测与计时 hook（支持 measured=false 完全不挂监听）
lib/useWakeLock.js 屏幕常亮，支持 20s 续期与页面回前台时重新获取
lib/basePath.js   部署基路径（服务端与客户端共用的唯一来源）
public/sw.js      离线壳：导航网络优先，/_next/static 缓存优先
tools/serve.mjs   零依赖静态服务器（预览导出产物，打印局域网地址供手机访问）
tools/contrast.mjs  对比度门禁：从 tokens.css 读token 算WCAG，退出码即CI 门禁
tools/make-icons.py  用 stdlib 生成图标集（改了想重新生成就跑它）
tests/run.mjs   27 项纯断言，node tests/run.mjs
tests/harness.html + tests/e2e.mjs   76 项浏览器断言，node tests/e2e.mjs <url>
DEPLOY.md      部署指南
out/           构建产物（纯静态，约 1.2 MB，含自托管字体）
```
